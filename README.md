# Intelligent-Vehicle-Laser-Countermeasures
项目
临时展示，一些简单介绍如下：
视觉部分和系统集成设计：
系统采用“树莓派 + STM32”主从架构：树莓派承担高算力视觉识别与算法决策，STM32负责云台转动、底盘运动及避障等底层实时控制，实现任务分层与高效协同。
在视觉计算机部署方面，选用轻量级YOLOv8n模型，基于1000张纸带图片进行差异化训练，以适配边缘计算设备的算力约束。训练完成后，模型导出为PyTorch原生格式（pt）与开放神经网络交换格式（onnx），保障跨平台部署与推理兼容性。

电控部分优化
执行器与云台建模（基础闭环构建）
系统以视觉偏差为输入，经PID控制器输出控制参数，由STM32输出PWM信号驱动云台。通过图像反馈更新位置，构建起“视觉偏差—PID—PWM—云台—图像反馈”的完整闭环控制链路，并完成执行器与云台的初步建模。
PID简化与控制性能优化（动态响应提升）
针对开环云台缺乏速度反馈的局限，系统采用视觉伺服方案。结合频域辨识结果对控制参数进行校正，优化系统的动态响应性能，并在Simulink环境中完成PID简化与性能验证（含阶跃响应与参数拟合分析）。
扫频激励与系统辨识（模型量化分析）
向系统注入0.1-3Hz的扫频信号，基于单点扫频数据拟合估计系统频响，绘制Bode图。通过建立的模型，量化系统的相关动态性能，为控制策略提供频域层面的理论支撑，并结合实际物理场景（如目标纸带识别与云台实物测试）进行验证。
